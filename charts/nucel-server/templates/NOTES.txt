{{- if $multi }}

  Running MULTI-REPLICA (server.replicas={{ $replicas }}{{ if $hpaOn }}, HPA enabled{{ end }}).

  For multi-replica each shared data class (pages / registry / npm / artifacts)
  MUST be reachable from every pod. The chart has validated your config and
  refused to deploy a ReadWriteOnce PVC or emptyDir on a shared class (that is
  the Multi-Attach / 404-race bug in #244). Recommended:

    * pages     → storage.classes.pages.backend=s3   (object storage, IRSA)
    * registry  → storage.classes.registry.accessMode=ReadWriteMany (EFS/NFS)
    * npm       → storage.classes.npm.accessMode=ReadWriteMany
    * artifacts → storage.classes.artifacts.accessMode=ReadWriteMany

  registry / npm / artifacts are filesystem-only in the binary today, so S3 is
  NOT yet an option for them — use a ReadWriteMany StorageClass.
